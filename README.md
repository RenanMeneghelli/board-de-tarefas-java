# 📝 Board de Tarefas em Java

Este projeto é um board de tarefas simples desenvolvido em Java, seguindo boas práticas de programação, separação em camadas e persistência de dados. Foi criado com foco em aprendizado e estruturação de projetos Java puro (sem frameworks).

## 🚀 Funcionalidades

- Criar tarefas com título e descrição
- Listar tarefas existentes
- Atualizar status das tarefas (ex: Pendente, Em andamento, Concluído)
- Remover tarefas
- Armazenamento de dados em memória (ou opcionalmente em arquivo `.txt`)

## 🛠️ Tecnologias e Práticas

- Java 17+
- Programação Orientada a Objetos (POO)
- Separação por camadas (Model, Repository, Service, View)
- Boas práticas de organização de código
- Interface em terminal
